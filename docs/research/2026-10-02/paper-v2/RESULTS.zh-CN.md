![Model, robot and evaluation boundaries](../../../media/evidence-boundaries.svg)

[完整英文报告](RESULTS.md) · [冻结方案](PROTOCOL.md) · [复现命令](../../../../experiments/research_v2/README.md)

[实验设计总表](EXPERIMENT_MATRIX.md)逐项对应科学问题、冻结样本、对照、统计单位和失败计数规则。

正式实验先提交源码、策略、样本划分和指标，再运行正式样本。预检与正式 seeds 分离；同一个初态上的候选和策略配对比较。硬件是 **RTX 4090 D（24 GB）**。物理接触与机械臂校验由 CPU MuJoCo 计算，视觉推理与渲染使用 GPU。

## 最严重的失败是什么

原来的低摩擦实验中，四个候选动作全部不安全，两个学习模型仍然各选出一个。预测模型无法从一个全都失败的候选集合里选出安全动作。相机改变也破坏了视觉模型的原校准条件。

修复采用明确的配置边界：相机不匹配时，在仍有可信物体状态和标称物理条件的前提下改走状态模型；声明摩擦下界时，增加更长的物理后备动作。摩擦、质量和未来结果的真实值只供评估器记录，不作为路由决策输入。错误的配置声明仍会导致失败。

## 新的 600 个样本说明了什么

每种场景 100 个独立初态；每个初态比较六个候选。主结果覆盖 5 秒执行和 0.5 秒保持。完成要求无观测风险/掉落，且托盘终点误差不超过 1 厘米。拒绝计为未完成。

| 场景 | 集成路由：风险 / 完成 / 拒绝 | 固定 4.8 秒：完成 |
|---|---:|---:|
| 标称条件 | 0 / 100 / 0 | 100 |
| 声明低摩擦 | 0 / 100 / 0 | 100 |
| 相机变化 | 0 / 100 / 0 | 100 |
| 低质量 | 0 / 0 / 100 | 100 |
| 高质量 | 0 / 0 / 100 | 100 |
| 1.35 倍位移 | 0 / 0 / 100 | 100 |

集成路由只完成 **300/600**，固定 4.8 秒完成 **600/600**。因此“零次观测到不安全选择”不能掩盖可用性损失。标称与相机分支的平均动作时长为 1.256 秒；低摩擦分支全部采用 4.8 秒。每组 100 个样本的零事件 Wilson 95% 上界约为 3.70%。

另有 100 对反事实初态：观测、动作、状态、质量和非摩擦模型相同，只改变观测后的接触摩擦。1.6 秒动作的风险结果在 100/100 对中不同，4.8 秒在 0/100 对中不同。这说明隐藏的未来接触变化可能无法由现有输入区分；它并不说明主动探测永远无法识别静态摩擦。

## 后备动作扩大到哪些条件

另一份在执行前冻结的方案覆盖 **27 组、324 个新样本**：摩擦 0.015–0.8、载荷 0.02–0.20 kg、位移尺度 0.8–1.5。每组八个参数角点和四个随机内部点。

| 策略 | 观测风险 | 掉落 | 完成 |
|---|---:|---:|---:|
| 固定 1.6 秒 | 140/324 | 78/324 | 184/324 |
| 固定 4.8 秒 | 0/324 | 0/324 | 324/324 |
| 声明下界筛选 | 0/324 | 0/324 | 324/324 |

慢速动作完成率提高 43.21 个百分点，配对 bootstrap 95% 区间为 37.96–48.77。整体零风险事件上界为 1.17%，但单组只有 12 个样本，其零事件上界仍为 24.25%。这支持冻结仿真条件下的慢速物理后备，不构成连续参数域或真机资格验证。

对已保存候选做事后诊断，未选中的 3.2 秒动作仍有 23/324 次风险、6/324 次掉落；风险集中在低摩擦且位移较大的组合。它不是新增的预设策略比较，也未用于调参。这说明先前较窄条件下安全的 3.2 秒动作不能直接推广。

下界规则在所有样本上都选择 4.8 秒，结果与固定 4.8 秒完全相同，耗时是 1.6 秒的三倍。它没有证明自适应时长优势，也没有实际触发拒绝分支。快速策略的失败主要集中在低摩擦组；新增保持阶段未引入额外风险。

## 增量校验是否真的更快

60 个新机械臂样本先独立采样障碍物，再生成计划。更密集的独立复核标记 23 个不安全、37 个安全。完整校验与绑定后的增量校验判定完全一致，均零次观测到误放行或误拒绝；只检查父计划误放行 20/23。零次误放行的分母只有 23，对应描述性 Wilson 上界仍为 14.31%。

排除预热后，每种方法运行三次并轮换顺序。完整校验平均边际成本 85.351 ms，增量为 84.356 ms，节省约 **0.996 ms**。两者计入相同父计划成本后，P95 为完整 223.214 ms、增量 226.218 ms。**没有尾延迟改善**。障碍自然采样只产生三个碰撞案例，危险类型的丰富程度仍有限。

## 原生模型闭环：100 个固定任务

独立协议与源码在正式运行前冻结到 `c3b9f9f`。官方 `lerobot/smolvla_libero` 在匹配的 LIBERO/Panda 环境中运行：两路相机、八维状态、七维相对动作。它与已发布的 SO100 overlay、UR5e 研究分别评估；观察器不改动作。

结果是 **58/100 成功，58.0%**，描述性 Wilson 95% 区间 **48.21%–67.20%**。十种任务各十次，成功数依次为 **7、6、8、7、3、0、8、8、4、7**。“从小盅上抓起黑碗”任务十次全部失败。42 次失败均达到 280 步上限且官方 reward 为零；58 次成功在 79–178 步结束。仅凭这些数据不能判断具体是抓取、放置还是初态物理出了问题。

100 个实际重置与计划 state/seed 一致；404 次动作块推理、17,868 组后处理/仿真动作完全相同，最大差值为零，干预数为零。总墙钟耗时 29.04 分钟，包含仿真、推理和记录，不是纯推理延迟或真机实时性能。[完整 manifest](libero/manifest.json)绑定模型、归一化器、tokenizer、资产、任务初态、原始 trace 和录像。

[原生模型视频](https://github.com/LancerLSY/sentinel-evc-lab/releases/download/paper-validation-20261002/libero-task00-state00-explained.mp4)使用运行前指定的 task0/state0，真实结果为 83 步成功。360×360 原始 RGB 放在 1080p 双语画布上；放大和字幕不增加场景细节。原文件标记 80 fps，讲解版按真实 20 Hz 控制时钟播放为 4.15 秒。这个成功案例不替换整体统计中的失败样本。

[SmolVLA 原论文 Table13](https://arxiv.org/pdf/2506.01844)提示：执行整块 50 个动作会比每十步重新观察更弱。因此另外设计使用新初始状态的配对消融，保留原来的 58/100 结果。上游关于 MuJoCo 重置版本的[未解决报告](https://github.com/huggingface/lerobot/issues/4390)只作为初态审计线索，不能直接当作失败原因。

## 重新观察间隔消融：20 对、40 次闭环

[动作执行长度协议](REPLAN_PROTOCOL.md)在正式运行前冻结到 `d1b4b1c`。任务 5 为主要失败任务，任务 0 为对照，均使用新的状态 10–19。模型仍预测 50 个动作；两分支分别执行 50 或 10 步后重新观察。权重、处理器、MuJoCo 3.8.1、初态文件和配对 seed 相同；交替分支顺序，每次重置模型。全部 20 对初始状态、相机哈希及前十个预测动作完全相同。

| 任务 | 执行 50 步 / 10 步 | 配对成功率变化 | 描述性 bootstrap 95% |
|---|---:|---:|---:|
| 5：小盅上的碗，主端点 | 0/10 → 1/10 | +10 个百分点 | 0–30 个百分点 |
| 0：对照 | 8/10 → 10/10 | +20 个百分点 | 0–50 个百分点 |

**严重失败尚未解决**：频繁反馈后，任务 5 仍失败 9/10。小样本区间包含零，不能据此主张模型整体提升。改善分别来自任务 5 的状态 16、任务 0 的状态 14 和 18。零次崩溃、零次干预；40 次 state/seed 重置全部正确，7,510 组后处理到仿真动作最大差值为零。[完整配对 manifest](replan/manifest.json)绑定原始 trace。

任务 5 平均带记录的墙钟耗时由 26.76 秒增加到 30.72 秒，每个动作对应的推理块由 0.02143 增至 0.10024。对照耗时由 12.64 秒降到 10.16 秒，是因为两个长超时失败变成成功，不说明单次推理更快。正式总耗时 803.39 秒。这是重新观察间隔的消融，与论文的异步重叠块方法分开。

## 仿真版本初态审计：40 次无策略重置

[重置协议](RESET_AUDIT_PROTOCOL.md)与源码在正式执行前冻结到 `c7bfa7d`。任务 0 和 5、未用于原 100 次评价的状态 10–19，在 MuJoCo 3.8.1 与隔离的 3.3.7 下配对：任务文件、资产、seed 和重置设置完全相同。共 20 对、40 次重置，不加载模型，不执行动作；正式 manifest 绑定两份排除的预检凭据。

任务 5 的碗位置在 **10/10 对中都相差 35.327 毫米**，姿态相差 **0.24724 弧度**，碗相对小盅的位置相差 35.782 毫米。任务 0 对照的碗位置平均只差 **0.688 毫米**，最大 3.564 毫米。两路相机在全部配对中均有差异。这证明模型第一次动作之前，任务 5 的物理初态已对版本敏感；它还不能证明初态差异造成原来的 0/10。[逐对数据](reset-audit/comparison/paired_records.json)与[汇总凭据](reset-audit/comparison/comparison.json)绑定全部原始状态和图像。

[MuJoCo 官方 3.4.0 变更](https://mujoco.readthedocs.io/en/stable/changelog.html#version-3-4-0-december-5-2025)记录了盒体接触距离的错误修正；[上游 LIBERO 报告](https://github.com/huggingface/lerobot/issues/4390)提出旧基准的重置依赖此前接触行为。因此 3.3.7 对照研究的是基准版本兼容性，不能说旧物理引擎更准确。官方初态文件没有修改；模型实际成功率的版本效应由另一个先冻结的闭环实验评价。

目标碗体中心最高只比初态上升 **1.674 mm**，终点下降 **30.947 mm**、总位移 46.513 mm。与盘子体中心的距离始终不小于 288.175 mm。目标碗体中心到**观测 EEF 位置**的最近距离为 77.189 mm；它不是指尖间隙、接触证据或抓取标准，视频中的 “Bowl-gripper distance” 指这一中心到 EEF 的测量。另一只碗的位置基本不变。这些数据描述运输失败，不据此推断具体原因。[位姿诊断](libero-failure/pose_diagnostic.json)与[完整来源清单](libero-failure/manifest.json)保留证据。

## 视频里的红色和绿色表示什么

[版本配对回放](backend/BACKEND_REPLAY.md)选择任务 5 中按初态顺序排列的第一组结果不同样本：state 21、seed 43022。逐项重放正式下发动作后，MuJoCo 3.8.1 在 280 步后失败、奖励为 0；3.3.7 在第 85 步成功、奖励为 1。各分支的初始机器人状态、相机、全部动作和官方逐步结果均匹配原记录。1080p、20 fps 视频共 280 个展示帧，较短分支的最后一帧保持 195 帧（9.75 秒），字幕明确说明这段没有新增仿真动作或运动。

这项事后诊断不增加正式实验样本、不调用策略推理、没有观察器干预。回放采用单独冻结并逐文件校验的官方资产绑定，见[复现说明](REPRODUCIBILITY_NOTE.md)。结果支持完整版本处理的兼容性差异，不据此判断哪个版本更接近真实物理，也不单独确定失败原因。[数据、源码与视频](https://github.com/LancerLSY/sentinel-evc-lab/releases/tag/simulator-replays-20261002)。

两段均为 1080p、中英双语，重建真实保存的 MuJoCo 状态，不由图像生成模型制作。统计结论来自完整实验集合，不能由单个视频替代。

## 保留的缺口

SO100 微调模型的指标仍是记录数据上的动作重建误差，不能换算成机械臂任务成功率。原集成路由的质量和位移拒绝没有被事后改成成功。神经模型、物理后备与最终动作许可链仍需要按各自 profile 完成产品接入；真机运动写入适配器和硬件验证尚未建立。

匹配机械臂的官方 SmolVLA/LIBERO 闭环实验采用[单独冻结协议](LIBERO_PROTOCOL.md)，与 SO100 模型及 Sentinel 干预收益分开报告。
