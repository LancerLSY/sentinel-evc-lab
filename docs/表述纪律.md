# 表述纪律

对外材料（README、论文、答辩、路演、招商）统一遵守下表。

| 想说的话 | 前置条件 |
| --- | --- |
| 「减少了 X% 完整检查调用」 | 必须同时报告父证书建立成本、失败回退成本、端到端墙钟时间。只数函数调用次数不算数 |
| 「接入了真实 VLA」 | 加载了实际检查点并跑了推理。只跑通仿真环境不算 |
| 「实现了闭环」 | 门禁真的改变了发送的动作。影子模式不算 |
| 「零违规」 | 必须跟一句「在本组 N 个构造案例、该约束族范围内」 |
| 「测试通过 N 项」 | N 只能是本仓库自己的数字。历史包的 57 / 50 / 12 / 65 / 51 项不能累加 |
| 「实时」 | 指在指定硬件与任务下测量并管理动作有效期，不对应硬实时或功能安全等级 |
| 「保证安全」 | 任何条件下都不说 |

## 三句必须常说的话

1. 本项目里的「许可」「证书」「验证」都有具体适用范围，不是功能安全认证、
   不是物理停止证明、不是事故责任判断。
2. dt=50 ms、K≤4、tracking reserve 等数值都是**这个数值 profile 的配置**，
   不是任何机器人的安全速度或人体保护距离。
3. 「零次观测到失效」只说明这组测试没发现这类问题，不等于任意场景零事故。

## 三类信息必须分开标注

- **来源记载**：历史文档描述的成果，本轮未独立复验
- **工程建议**：新增的范围、工时、角色和目标
- **本次实测**：随包代码、测试与运行记录能支撑的结论

任何一句对外表述，都要能说清它属于哪一类。
