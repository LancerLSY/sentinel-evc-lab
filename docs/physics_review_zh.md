# 三维接触仿真与 SSH 实验：机制审查

本文记录三维接触实验基础版本与 v4 机制的对应关系，包括候选分叉、控制器反馈、撤销和证据绑定。完整接口、边界及实验协议见 [physics_ssh_design.md](physics_ssh_design.md)。原始私有设计文档、SSH配置和凭据均不进入仓库。

| 项目 | 当前结果 |
|---|---|
| 最终动作、证书、授权、单次消费、撤销 | 原有机制保留；新增实际控制器反馈时间绑定，拒绝把旧反馈重新标为新状态 |
| 三维物理 | 真实 MuJoCo：XYZ驱动托盘、自由刚体载荷、重力、摩擦、地面接触；测量实际状态，执行中不瞬移到命令位置 |
| 场景与物理参数冻结 | 哈希绑定完整编译模型、源XML和工作区；参数变化使旧证书失效 |
| 候选分叉与复现 | 每个分辨率从同一完整积分状态分叉；完整轨迹复现检查通过 |
| 撤销与停止 | 禁止旧代次新增提交；保留已接受尾部；撤销后继续积分并记录载荷运动 |
| 实验选择 | 在查看未来结果前按几何可行性选最快候选；它确实发生滑移，保留失败 |
| 证据 | 25个试验签名包＋实验汇总签名索引；源代码、测试、依赖版本、配置和锚点绑定；可见汇总必须与签名汇总相同 |
| SSH | 隔离作业目录、远端安装和完整测试、物理实验、严格主机校验、受限归档、安全回传与本地验证已实现 |
| 在线三维 WorldGuard、真实VLA、机械臂、真机 | 尚未实现，保留独立实验与前置条件 |

严格步长收敛检查使用五档分辨率，网关轮询固定2ms，最终比较.25ms/.125ms。最快.6s分支的终态位置和姿态未通过；.9/1.2/1.6s分支通过。9项实验门中8项通过，失败项保留为失败。运行完成与科学结论通过是两个状态；退出码3可以携带完整有效的负面实验结果。

这个场景是开口托盘与地面，未建立真实机械臂连杆碰撞、物理围墙、视觉反馈或学习模型的三维安全证明。原数值操作台及其一维校准结果不用于授权这个物理试验。未来应先解决快分支的接触敏感性与收敛，再接真实VLA影子记录和独立根分组训练校准。

SSH实际验证尚未完成：需要指定主机并获得可用认证。现有入口使用密钥、agent或已登录连接，不读取密码注释，不修改known_hosts。遇到主机密钥变化直接拒绝。回执只绑定采集时的SSH传输，必须另行保管；演示签名密钥与未签名本地回执不构成客户PKI或可转移远程证明。
