# Sentinel EVC Lab

> 给机器人策略的动作块加一道最终提交前的门禁 —— 验证的是真正要被执行的那个动作，
> 许可有期限、只能用一次、可以撤销，整个过程留下第三方能独立校验的记录。

---

## 这是什么，不是什么

**能力状态表**（本表是项目最重要的诚信装置，任何时候都应与仓库实际状态一致）

| 能力 | 当前状态 | 明确不承诺 |
| --- | --- | --- |
| 动作合同与哈希 | 未开始 | 不覆盖真实机械臂逆运动学 |
| 几何完整检查 | 未开始 | 不覆盖连杆、夹爪、载荷、动态障碍 |
| Δ-Cert 增量继承 | 未开始 | 不覆盖速度、加速度、夹持、接触 |
| 一次性执行许可 | 未开始 | 不是 PKI，不是功能安全 |
| 撤销屏障 | 未开始 | 不是电机制动证明 |
| 证据哈希链与签名 | 未开始 | 只证明记录完整性，不证明传感器诚实 |
| 真实 VLA 接入 | 未开始 | v0.2 目标是影子模式，不是闭环干预 |
| WorldGuard | 仅保留接口 | 无训练、无实验、无结论 |
| 真机 | 未开始，不在本轮范围 | —— |

**三句必须常说的话**

1. 「许可」「证书」「验证」在本项目里都有具体适用范围，**不是功能安全认证、不是物理停止证明、不是事故责任判断**。
2. 数值实验里的 `dt=50 ms`、`K≤4`、tracking reserve 都是**这个数值 profile 的配置**，不是任何机器人的安全速度或人体保护距离。
3. 「零次观测到失效」只说明这组测试没发现这类问题，**不等于任意场景零事故**。

## 架构

计划中的模块划分（尚未实现）：

```
src/sentinel_evc/
├── contracts.py       # 不可变对象 + 规范化哈希
├── geometry.py        # 线段-球精确距离、盒边界、完整检查
├── delta_cert.py      # 余量账本、继承判定、依赖失效
├── authority.py       # Lease 签发、HMAC、一次性消费
├── executor.py        # 单写者、逐步 dispatch、撤销屏障
├── sim_controller.py  # 有容量的模拟控制器 + ACK
├── events.py          # 事件定义、有界队列、JSONL 写出
├── evidence.py        # 哈希链、manifest、Ed25519 签名与校验
├── report.py          # 生成静态 report.html（含内联 SVG）
├── scenarios.py       # 场景与轨迹构造、批量实验
└── cli.py             # demo / geometry / fault / verify
```

运行时依赖只允许两个：`numpy`、`cryptography`。
